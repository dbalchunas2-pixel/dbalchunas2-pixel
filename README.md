# Hi, I'm David Balchunas Jr.

I build tools that connect AI agents to the real world - and I found a sustainability company along the way.

Most of my work is **MCP (Model Context Protocol) servers**: software that lets AI assistants read Apple Notes, manage Railway deployments, bridge Google Drive backups, and automate Safari. I like working at the seam where AI meets actual systems - local-first, deployed, and in daily use.

## What I'm working on

- **Founder, Balchunas Sustainability** - building technology-driven sustainability solutions, from farm operations planning to deployment infrastructure
- **AI agent tooling** - a growing family of MCP servers in Python, TypeScript, and JavaScript, hosted on Railway and running in production
- **Personal portfolio** - a multi-page dynamic site with a custom generative-art layer, live at [davidbalchunas.com](https://teal-fenglisu-ca003b.netlify.app)

## Featured projects

| Project | What it does |
|---|---|
| [notability-ai-bridge](https://github.com/dbalchunas2-pixel/notability-ai-bridge) | Multi-user SaaS MCP server bridging Notability PDF auto-backups from Google Drive to any AI assistant. OAuth 2.0, usage metering, API-key auth, deployed on Railway |
| [notability-mcp-server](https://github.com/dbalchunas2-pixel/notability-mcp-server) | Single-tenant MCP server that reads Notability notes from Google Drive so AI assistants can search and read them |
| [apple-health-mcp-tunnel](https://github.com/dbalchunas2-pixel/apple-health-mcp-tunnel) | Railway WebSocket tunnel exposing a local Apple Health MCP server to remote clients |
